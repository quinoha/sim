# QEC Test Vector Generator

![Python Version](https://img.shields.io/badge/python-3.11%2B-blue.svg)

**Made using Stim/Sinter Libraries**

## Purpose
The main objective of this repo is to make a surface code / BB code circuit and inject error model noises to replicate quantum circuit level environment, and extract the ancilla qubit readout as hex files to use in FPGA/ASICs. 

## Core Method


## Features
Key Features are:
1. Customizable / Scalable surface & BB code circuits.
2. Adjustable noise model.
3. Golden model (python-based) answers to compare with the binary data.
4. Circuit-to-hex for further use.
